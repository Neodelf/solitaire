# Руководство по улучшению Google Analytics для World Solitaire

## Обзор улучшений

Данный набор улучшений значительно расширяет возможности аналитики для игры Solitaire, предоставляя детальную информацию о поведении пользователей, производительности и возможностях монетизации.

## Установленные модули

### 1. Analytics.js - Основной модуль аналитики
- **Файл**: `analytics.js`
- **Функции**:
  - Отслеживание игровых событий (начало, ходы, победа, поражение)
  - Мониторинг вовлеченности пользователей
  - Расчет эффективности игры
  - Отслеживание ошибок

### 2. Performance-tracker.js - Трекинг производительности
- **Файл**: `performance-tracker.js`
- **Функции**:
  - Мониторинг времени загрузки страницы
  - Отслеживание FPS игры
  - Мониторинг использования памяти
  - Отслеживание ошибок JavaScript

### 3. Custom-dimensions.js - Пользовательские измерения
- **Файл**: `custom-dimensions.js`
- **Функции**:
  - Определение типа устройства и браузера
  - Классификация навыков игрока
  - Измерения производительности
  - Сегментация пользователей

### 4. Ecommerce-tracker.js - Трекинг электронной коммерции
- **Файл**: `ecommerce-tracker.js`
- **Функции**:
  - Отслеживание покупок и подписок
  - Мониторинг воронки конверсии
  - Анализ удержания пользователей
  - A/B тестирование

## Настройка Google Analytics 4

### 1. Пользовательские измерения (Custom Dimensions)

В интерфейсе GA4 необходимо создать следующие пользовательские измерения:

| Измерение | Параметр | Описание |
|-----------|----------|----------|
| cd1 | game_type | Тип игры (klondike, spider, etc.) |
| cd2 | game_session_id | Уникальный ID игровой сессии |
| cd3 | player_skill_level | Уровень навыков игрока |
| cd4 | game_difficulty | Сложность игры |
| cd5 | device_type | Тип устройства (mobile/tablet/desktop) |
| cd6 | screen_resolution | Разрешение экрана |
| cd7 | browser_type | Тип браузера |
| cd8 | language | Язык пользователя |
| cd9 | page_load_time | Время загрузки страницы |
| cd10 | game_fps | FPS игры |
| cd11 | memory_usage | Использование памяти |
| cd12 | error_count | Количество ошибок |
| cd13 | session_duration | Длительность сессии |
| cd14 | moves_per_game | Ходов за игру |
| cd15 | hints_used | Использованных подсказок |
| cd16 | undos_used | Использованных отмен |
| cd17 | premium_features_used | Использованных премиум функций |
| cd18 | ad_interactions | Взаимодействий с рекламой |
| cd19 | conversion_funnel_step | Этап воронки конверсии |

### 2. Пользовательские события (Custom Events)

Система автоматически отправляет следующие события:

#### Игровые события
- `game_start` - Начало новой игры
- `card_move` - Перемещение карты
- `game_won` - Победа в игре
- `game_lost` - Поражение в игре
- `auto_win_used` - Использование авто-победы
- `game_paused` - Пауза игры
- `game_resumed` - Возобновление игры

#### События производительности
- `page_load` - Загрузка страницы
- `card_rendering` - Рендеринг карт
- `memory_usage` - Использование памяти
- `game_fps` - FPS игры
- `click_response` - Время отклика на клики

#### События электронной коммерции
- `view_item` - Просмотр товара
- `add_to_cart` - Добавление в корзину
- `purchase` - Покупка
- `subscribe` - Подписка
- `conversion_funnel` - Этап воронки конверсии

### 3. Настройка Enhanced Ecommerce

В GA4 включите Enhanced Ecommerce и настройте следующие параметры:

```javascript
gtag('config', 'G-6CEHHD053K', {
  enhanced_ecommerce: true,
  currency: 'USD'
});
```

## Отчеты и дашборды

### 1. Игровая аналитика
- **Игровые сессии**: Количество и длительность игровых сессий
- **Эффективность игроков**: Среднее количество ходов до победы
- **Уровень вовлеченности**: Время игры, количество игр за сессию
- **Сложность игр**: Анализ сложности по количеству ходов и времени

### 2. Производительность
- **Время загрузки**: Core Web Vitals и другие метрики производительности
- **FPS игры**: Мониторинг плавности анимаций
- **Использование памяти**: Отслеживание утечек памяти
- **Ошибки**: Количество и типы ошибок

### 3. Пользовательское поведение
- **Сегментация по устройствам**: Анализ поведения на разных устройствах
- **Сегментация по навыкам**: Поведение новичков vs экспертов
- **Воронка конверсии**: Путь от первого клика до покупки
- **Удержание пользователей**: Когортный анализ

### 4. Монетизация
- **Конверсия**: Процент пользователей, совершивших покупку
- **ARPU**: Средний доход на пользователя
- **LTV**: Пожизненная ценность клиента
- **A/B тесты**: Результаты экспериментов

## Рекомендации по использованию

### 1. Мониторинг в реальном времени
Используйте Real-time отчеты GA4 для мониторинга:
- Активных игровых сессий
- Ошибок в реальном времени
- Производительности игры

### 2. Настройка алертов
Создайте алерты для:
- Резкого падения FPS
- Увеличения количества ошибок
- Снижения конверсии
- Проблем с производительностью

### 3. Автоматизация отчетов
Настройте автоматические отчеты для:
- Еженедельной аналитики игр
- Ежемесячного анализа производительности
- Квартального анализа монетизации

### 4. Интеграция с другими инструментами
Рассмотрите интеграцию с:
- **Google Data Studio** для создания дашбордов
- **Google Optimize** для A/B тестирования
- **Firebase** для дополнительной аналитики мобильных устройств

## Примеры использования данных

### 1. Оптимизация игрового процесса
```javascript
// Анализ эффективности игроков
const playerEfficiency = analytics.getPlayerEfficiency();
if (playerEfficiency < 50) {
    // Предложить подсказки новичкам
    showHintButton();
}
```

### 2. Персонализация опыта
```javascript
// Определение уровня навыков
const skillLevel = customDimensions.calculatePlayerSkillLevel(gameStats);
if (skillLevel === 'expert') {
    // Показать сложные задачи
    showExpertChallenges();
}
```

### 3. Оптимизация производительности
```javascript
// Мониторинг FPS
const fps = performanceTracker.getCurrentFPS();
if (fps < 30) {
    // Уменьшить качество анимаций
    reduceAnimationQuality();
}
```

## Техническая поддержка

Для получения дополнительной помощи:
1. Проверьте консоль браузера на наличие ошибок
2. Используйте Google Analytics Debugger для отладки
3. Мониторьте Network tab для проверки отправки событий
4. Используйте Real-time отчеты для проверки работы событий

Регулярное использование этих данных поможет значительно улучшить пользовательский опыт и увеличить доходность проекта.
